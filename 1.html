数学 · 第7题 抛物线的点对圆两切线的夹角

题目：已知 P 为抛物线 x² = 4y 上一点，过 P 作圆 x² + (y−4)² = 1 的两条切线，切点分别为 A、B，则 cos∠APB 的最小值是（ ） A. 1/2  B. 5/6  C. 3/4  D. 7/9 答案 B（5/6）你的作答正确 ✓
  1. 圆心 C(0, 4)，半径 r = 1。由切线性质 CA⊥PA，设 ∠APC = θ，则 sinθ = r/|CP| = 1/|CP|，且 ∠APB = 2θ。
  2. 二倍角公式统一变量：cos∠APB = 1 − 2sin²θ = 1 − 2/|CP|²。所以 |CP| 越小，cos∠APB 越小（P 离圆越近，夹角越大）。
  3. 设 P(x, x²/4)：|CP|² = x² + (x²/4 − 4)² = (x²−8)²/16 + 12 ≥ 12，当 x² = 8（即 y = 2）时取最小值 12。
  4. 最小值 = 1 − 2/12 = 5/6。

数学 · 第6题 椭圆上关于直线对称的弦中点

题目：椭圆 x²/8 + y²/4 = 1 上两点 A、B 关于直线 2x − y − 1 = 0 对称，则弦 AB 的中点坐标为（ ） A. (1,1)  B. (1, 1/2)  C. (−1, 1)  D. (2, 1/2) 答案 A（1, 1）
  1. 「A、B 关于直线 l 对称」⇒ l 是 AB 的垂直平分线：中点 M 在 l 上，且 kAB · kl = −1。由 kl = 2 得 kAB = −1/2（卷面这步是对的）。
  2. 点差法：A、B 代入椭圆方程相减：(x₁+x₂)(x₁−x₂)/8 + (y₁+y₂)(y₁−y₂)/4 = 0。用 x₁+x₂ = 2x₀、y₁+y₂ = 2y₀、kAB = (y₁−y₂)/(x₁−x₂) 代入，得 kAB = −x₀/(2y₀)。
  3. 令 −x₀/(2y₀) = −1/2 ⇒ x₀ = y₀；联立直线方程 2x₀ − y₀ − 1 = 0，解得 x₀ = y₀ = 1。
  4. 检验：1/8 + 1/4 = 3/8 < 1，M 在椭圆内部，弦真实存在。
易错点：点差法结论 k = −b²x₀/(a²y₀) 中，本题 a² = 8、b² = 4，系数是 4/8 = 1/2，不要代成 2。

物理 · 第7题 自行车霍尔速度计

题目：自行车速度计可利用霍尔效应传感器获知运动速率。一块磁铁安装在前轮上，轮子每转一圈，磁铁就靠近传感器一次，输出一个脉冲电压。电源输出电压为 U₁，磁场靠近霍尔元件时，在导体前后表面间出现电势差 U₂（前表面电势低于后表面）。说法正确的是（ ）
A. 图乙中霍尔元件的载流子带正电   B. 已知车轮半径，再根据单位时间内的脉冲数，即获得车速大小   C. 若电源输出电压 U₁ 变大，则霍尔电势差 U₂ 变小   D. 霍尔电势差 U₂ 的大小与霍尔元件所用材料无关 答案 B
  1. 测速原理（B 对）：单位时间脉冲数 = 车轮转动频率 n，车速 v = 2πrn。半径已知、频率可数，车速即得。
  2. 载流子正负（A 错）：电流方向与磁场方向已知，前表面电势低说明负电荷积累在前表面（正电荷积累则应前高后低），故载流子是负电荷（电子）——这也与霍尔元件一般用 N 型半导体一致。
  3. U₁ 的影响（C 错）：U₁ 变大 → 通过元件的电流 I 变大，由 U₂ = IB/(nqd)，U₂ 应变大。
  4. 与材料的关系（D 错）：U₂ = IB/(nqd)，载流子浓度 n 是材料属性，当然有关。

物理 · 第12题 霍尔元件（N 型半导体）

题目：霍尔元件由长×宽×厚 a×b×d、单位体积自由电子数为 n 的 N 型半导体制成。在 1、2 间通入电流 I，外加垂直工作面的磁场 B，接线端 3、4 间霍尔电压稳定后满足 UH = RH · IB/d，RH 为霍尔系数，仅与材料有关。下列说法正确的是（ ）
A. 接线端 3 的电势比接线端 4 的电势低   B. 自由电子受到的洛伦兹力大小为 eUH/d  （C、D 选项照片上未拍全） 答案 C

动图：电子从 2 端漂向 1 端，被洛伦兹力压向 4 端——先自己判断 3、4 谁电势高

  1. 电流微观式：I = neSv = nebd · v（横截面积 = 宽 b × 厚 d）⇒ v = I/(nebd)

  3. 代入 v：UH = vBb = IB/(ned)
  4. 对比题给 UH = RHIB/d ⇒ RH = 1/(ne)，只含材料量 n——这通常就是 C 选项的内容（正确项）
  5. A 选项：电子偏向端 4，φ₄ < φ₃，故「3 比 4 低」错误

物理 · 第8题 圆形磁场中各方向入射粒子的出射区域

题目：半径为 R 的圆形区域内有匀强磁场（方向垂直圆面），一群相同带电粒子以相同速率 v₀ 由 P 点沿纸面内不同方向射入。当磁感应强度为 B₁ 时，所有粒子射出磁场的区域占整个圆周长的 1/6；当 B 减小为 B₂ 时，出射区域占整个圆周长的 1/3。则 B₁:B₂ 为（ ） A. 1:√3  B. 2:√3  C. √3:1  D. 4:√3 答案 C（√3 : 1）你的作答正确 ✓
  1. 同种粒子同速率 ⇒ 轨迹半径 r = mv₀/(qB) 相同；方向不同 ⇒ 轨迹圆绕 P 旋转，出射点沿边界扫成一段弧。r 越大（B 越小），扫过的弧越长。
  2. 出射弧的最远点对应「半圆轨迹」：粒子速度 ⊥ PO₁ 时转半圆，出射弦最长 = 2r。
  3. 设出射弧圆心角为 2β，弦长公式：2r = 2R·sinβ ⇒ r = R sinβ。
  4. B₁：弧占 1/6 → 2β = 60° → r₁ = R sin30° = R/2；  B₂：弧占 1/3 → 2β = 120° → r₂ = R sin60° = √3R/2。
  5. B = mv₀/(qr) ∝ 1/r，故 B₁:B₂ = r₂:r₁ = √3 : 1。

化学 · 第15题 NO 转化率–温度图像（选错误说法）

题目：容积不变的刚性容器中按投料比 n(H₂)/n(NO) = 1 发生反应 2H₂(g)+2NO(g) ⇌ N₂(g)+2H₂O(g) ΔH = −664.1 kJ/mol。不同催化剂下，反应相同时间测得 NO 转化率与温度关系如图，反应速率 v = k·cᵊ(H₂)·c²(NO)。说法错误的是（ ）
A. 正反应活化能比逆反应小   B. 使用催化剂甲与乙相比，正反应活化能更低   C. 用催化剂乙时，高于 350°C 转化率下降是因反应放热，达平衡后升温平衡逆移   D. T₁°C 初始速率 V₀，H₂ 转化率 60% 时速率为 0.064V₀，可知 m = 1 答案 B

温度：
  1. A 对：ΔH = Ea正 − Ea逆 = −664.1 < 0 ⇒ Ea正 < Ea逆。
  2. B 错（答案）：图中转化率是「相同反应时间」测得的，并非平衡转化率。甲的曲线高只能说明相同时间内甲催化下反应更快（催化效率不同），但两种催化剂各自降低正反应活化能的多少，不能由这张图直接得出该结论——比较活化能需要速率常数 k 随温度的变化数据（阿伦尼乌斯图），转化率数据不够。
